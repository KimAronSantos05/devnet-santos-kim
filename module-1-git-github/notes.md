- repository:  A place where folder of a project will be contain
- commit: Its like a snapshot of every progress in a project. It can also inform by its message feature.
- branch:A separate place to experiment without affecting the main branch.
- push / pull: Its like a snapshot of every progress in a project. It can also inform by its message feature.
- pull request: Its creating a request to merge changes into one branchy into another branch.
